# Читалка og:image

По присланной ссылке (Pinterest, Instagram, что угодно) читает метатег
`og:image` и отдаёт байты картинки. Ничего не хранит, логов не пишет.
Разбор — в `docs/15_MOODBOARD.md`, раздел «Про посредника — и почему он
временный».

## Развернуть

Через мастер настройки Cloudflare (Workers → Create → вставить `worker.js`)
— или из терминала:

```bash
cd og-reader
npx wrangler login
npx wrangler deploy
```

Разворачивается как есть: без переменных окружения, без привязок KV/D1,
без секретов. После деплоя Cloudflare даст адрес вида
`https://light-plan-og-reader.<твой-подадрес>.workers.dev`.

## Проверить

```bash
curl "https://<адрес-воркера>/?url=https%3A%2F%2Fwww.pinterest.com%2Fpin%2F<id>%2F" -o test.jpg
```

Должен прийти файл картинки. Ссылка без og:image (или несуществующая
страница) — ответ 404, это ожидаемо: клиент в этом случае просто оставит
текстовую карточку, как было до читалки.

## Дальше

Адрес воркера нужно подставить в `beta/index.html` (константа
`OG_READER_URL`) — без этого читалка развёрнута, но ничем не вызывается.
