Как ведём работу: правки в `beta/index.html`, релиз получается копированием
(`cp beta/index.html index.html`) с заменой двух строк заголовка на «Light Plan»;
после `diff index.html beta/index.html` должен показывать ровно 4 строки.
`icons.js` копируется в `beta/` без изменений. Ветка `main`, пушим в `origin` —
это и есть выпуск на GitHub Pages.

Проверка: превью в песочнице отдаёт статический снимок и не перечитывает
`localStorage` извне — сценарии гоняй JS-вызовами в браузере (клик по элементам,
чтение DOM), чистые функции — headless через `jsc`. Node в системе нет; синтаксис
скриптов проверяется `osascript -l JavaScript` с `new Function(src)`.

Решения записываем: причина — в `DECISIONS.md`, спорное место в `docs/` правим с
датой и объяснением, пункт переносим в «Сделано» в `ROADMAP.md`. Если код спорит
с документом — спроси, что правда, и поправь неверное.
