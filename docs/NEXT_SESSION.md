## Правила, которые легко забыть

- Слияние в `main` натива — только по слову «сливай …», только ff; перед слиянием ветку при
  необходимости переносят на свежий `main` отдельным шагом (cherry-pick, не merge); один пуш на шаг
  (ревью GPT приходит на пуш в `wt/**`); ворота
  `make checkstep ARGS="wt/<имя> origin/main --type код --tests --full"`; ворота 4 для починки
  нестабильного теста и для переноса недостижимы по определению — оценивать порчей.
- Имя `wt/29-3g` занято старой веткой в истории; новые ветки брать с суффиксом.
- Диск мал (1,9–2,9 ГБ свободно после шага 29.11в, 14.10 было 15–18 ГБ): не больше одного
  полного прогона тестов; тред в конце шага удаляет свой симулятор и DerivedData.
- **PWA и веб-бета заморожены до финала переноса**; ошибки веба — `docs/web_defects.md`.
  Проверка прогноза для Москвы/Крыма в вебе не делалась.
- **Чужое, не трогать:** `beta/Знаки мест/`, `docs/PROMPT_*` (не в git).
