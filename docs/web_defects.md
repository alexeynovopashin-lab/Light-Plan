# Ошибки PWA (веб-беты) — список для правки

Найдены в ходе переноса на Swift. **PWA заморожен до финала переноса на Swift** (слово
Алексея, 30.09): править его начнём только после финала, по этому списку. Поэтому здесь копится всё, что стоит исправить в PWA и не повторять в версии
для Android. Подробности (строки кода беты, замеры) — в справке-источнике.

**Как вести.** Каждый отчёт шага с пунктом «ошибки веба» → строка здесь (ведёт
оркестратор). Идентификатор: буква области + номер в справке (К — карточка, М — мудборды,
О — организации и контакты, А — опросник). Статус: «открыта» = в вебе не исправлено;
«исправлена» — когда правку сделали. Колонка «Android»: **логика** — общая для платформ
(исправить и не повторять), **вид** — зависит от платформы, **веб** — только у PWA.
