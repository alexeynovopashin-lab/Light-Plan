# Журнал передачи

Работа над Light Plan идёт из двух мест: Cowork (разговор о замысле, разбор
снимков, проверка рендером) и Claude Code (код, git). Общей памяти у них нет —
связывает только репозиторий. Этот файл и есть связь: состояние передачи между
сеансами.

**Что пишется сюда.** Что сделано и в каком виде лежит на диске; что обсуждалось
и ещё не решено; ходы, которые отвергнуты, но могут вернуться. Одна запись —
один сеанс, в конце сеанса.

**Что не сюда.** Принятое решение с причиной — в [DECISIONS](../DECISIONS.md).
Очередь работ — в [ROADMAP](../ROADMAP.md). Порядок работы — в
[WORKFLOW](WORKFLOW.md). Здесь только то, что живёт между ними и умрёт, как
только решится.

Читается первым делом при передаче, вместе с `WORKFLOW.md`.

  чинил правильно.
