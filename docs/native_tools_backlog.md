# Хвост инструментов (оркестратор, 02.10)

- **Тексты экрана симулятора в лог.** Проверка на «LP 17Pro» (01–02.10) съела ~396 тыс. контекста и ~90 кадров: дерево доступности отдаёт только кнопки, кадры отстают на 1–2 действия, колесо времени снаружи не крутится. Нужен режим отладки приложения (только Debug), печатающий тексты и состояния текущего экрана в лог и принимающий команды «открыть экран / выставить время» по схеме `lightplan://debug/…`. Кандидат в итерацию инструментов после 28д.

## `make phone`: пул идентификаторов вместо нового на каждую ветку (03.10)

Бесплатная подпись Apple: не больше 10 новых App ID за 7 дней. `Tools/phone.sh` делает идентификатор из имени ветки (`wt28zh`), поэтому каждая новая ветка тратит один из десяти; 03.10 установка `wt/28zh` упала («maximum App ID limit has been reached»). Обход на 03.10: `LP_BRANCH=wt/28e make phone ARGS="install"` — код ветки ставится под уже зарегистрированным идентификатором (имя на телефоне «LP 28e», внутри другая ветка). Задача: фиксированный пул из трёх идентификаторов (`lpa`, `lpb`, `lpc`), ветка занимает свободный, имя на телефоне — «LP <ветка>», в строке «Сборка» настоящая ветка; не тратить новые App ID. Кандидат в итерацию инструментов.
