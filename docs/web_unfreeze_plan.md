# Разморозка веба: перенос функций натива в бету (с 31.10.2026)

Решение — DECISIONS 31.10 «Разморозка веба». Коротко: всё, что натив умеет и
что может работать в браузере, переносится в веб-бету **выключенным**.
Цель — основа для Android (Android начинается с PWA). Натив ломать нельзя:
веб для него — образец, из которого он берёт слова, таблицы и математику.

## 1. Что натив берёт из веба (проверено по `native:Tools`, 31.10)

| Что | Как читает | Правило для нас |
|---|---|---|
| `beta/lang.js` | `make lang`: все ключи → каталог строк; ключ, который есть и в `native:Tools/lang_native.json`, **останавливает генератор** | не трогать |
| `beta/icons.js` | `make icons`, копия внутри `index.html` сверяется с файлом | не трогать |
| `beta/sky.js`, `beta/mapstyle.js`, `beta/_seed_season.html` | целиком | не трогать |
| `tools/shot.js`, `window_light.js`, `datecheck.js`, `langcheck.js`, `pointwords_check.js` | целиком | не трогать |
| `beta/index.html` | `make parity`, `make domain`, `make lang`, `make blocks`: вырезка кода по якорным строкам | можно добавлять **только в самый конец файла** |
| живая страница беты | `make shots`, `make mapref` открывают её в браузере и меряют разметку | выключенный код не создаёт разметку и не пишет в хранилище |
| номера строк `index.html` | описания экранов для натива (`docs/native_2*_web_spec.md`) | в середину не вставлять — номера держатся |

**Страж:** `tools/native_guard.sh <папка натива> [база]` — файлы из таблицы
не изменены, а генераторы натива на базе и на рабочей копии дают побайтно
одно и то же (20 фикстур + вырезка по якорям). Пробы 31.10: без правок —
чисто; правка внутри вырезаемой функции — поймана. Сравниваем на одной
машине: с фикстурами Mac не сравниваем — node v22 здесь и v24 там дают
разную последнюю цифру дробей (измерено). Живая страница стражем не
проверяется — только правилом выше и снимком DOM до/после (Playwright),
когда в `index.html` появится строка подключения.

## 2. Устройство переноса

- Новый код — `beta/next/*.js`, свои слова — `beta/next/lang_next.js`
  (натив их не читает). В `index.html` — одна строка подключения в конце,
  когда понадобится первой функции (шаг 1), не раньше.
- Выключатель один: по умолчанию всё выключено и **скрыто полностью**
  (Алексей 31.10: «сделать все функции, но не делать их рабочими»; вид
  «скрыта» выбран из двух — «скрыта» / «приглушена» — как обратимый).
  Включается флагом для проверки и для будущей сборки Android.
- Функция не включается и для Android, если она конфликтует с нативом
  (Алексей 31.10). Конфликт = расходится с нативом в данных или числах:
  пишет в общий снимок не так, как натив; считает иначе (пример — «точное
  солнце»: если веб перейдёт на него, сверка натива с вебом сломается).
- Формат данных — нативный: ключи и формы записей как в `LightPlanDomain`
  (`clients`, `clientId`, `via`, `weekStart`, `notif.remind`, …), чтобы
  снимок, прошедший через веб, читался нативом без потерь.

## 3. Опись (из нативного CLAUDE.md и поиска по `beta/index.html`)

**Переносится целиком (выключенным):** клиенты К1–К3 (реестр, склейка по
номеру, «два из трёх», карточка, вход из съёмки, подсказка в форме);
К4 мессенджеры (разбор ссылок, ссылки, ★, значок кнопки); К5 стопка
несданных; К6 даты (дни рождения, годовщина, «Поздравлять») в карточке;
Поле-1 (шаг гостей, подвиды день рождения / девичник / мальчишник, звёзды
мессенджеров, «Позвонить админу»); Поле-2 «на связи через»; «Неделя
начинается» и цвет выходных; подпись «Фотосъёмка» для съёмки без жанра,
черновики из календаря, пометка «сдвинуто» у блока; отделка: закреплённые
✕/✓ формы, «Наверх», шапка ленты года, экран дня (мудборды первыми).

**Только заменой** (Android-Chrome может больше Safari): напоминание «за N
минут» и поздравления — push/уведомления; Контакты К7 — Contact Picker на
Android, vCard; зеркало Календаря — `.ics`. Решать по шагу.

**Не переносится** (нужен натив Android): AR и Млечный Путь в камере,
виджеты, экран активности / Dynamic Island, чужие календари призраками,
жест края. Для них — только текстовое описание, без кода.

**Отложено до решения Алексея:** «точное солнце» (29.8в.25) — конфликт с
нативной сверкой; три режима Просто/Про/Астро — в нативе ещё не построены.

**Уже в вебе:** «Музыка», «прогноз переменился» (`wxAnnounce`), гости
(старый шаг).

## 4. Защита данных натива (найдено 31.10, не правлено)

Слияние облака веба (`mergeStores`) сохраняет незнакомые ключи верхнего
уровня (`clients`, `weekStart`), но следующий `saveAll` собирает снимок из
переменных веба и их выбрасывает; ключи внутри съёмки (`clientId`, `via`)
переживают — `saveAll` копирует запись целиком. Натив облаком пока не
пользуется (шаг 31), обмен — только файлом, так что вред сейчас возможен
лишь по пути «файл с телефона → веб → файл обратно». Починка требует
правки `saveAll` в середине `index.html` — отдельным шагом со стражем.
