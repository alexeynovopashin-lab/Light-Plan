Собрана исполнителем шага 5 итерации 24 (28.09.2026) из `beta/index.html`
(веб `main` = `6294183`), чтобы 24а не читала веб заново. Имена функций и

Что уже есть в нативе после шага 5 (`wt/24` = `b40cb7b`): «Мои места» в шапке

## Данные

- `mapRoute` — массив id мест из «Моих мест» по порядку; `mapWalk` — объект
  `{ "<idA>><idB>": 1 }`: переход от A к B пешком (ключ — пара, не номер).
  Оба в снимке `saveAll` (у натива сейчас лежат в `Snapshot.extra`).
- `routeSpots()` — места черновика, у которых есть `lat`; удалённое место
  черновик переживает (пропускается). Черновик один на приложение.
- `mapShoot` (маршрут записанной съёмки «читать» на холсте) — зовут из
  карточки: **не 24а** (карточка — 25–27).

## Визир (`sightMorph`, `sightDraw`, `SIGHT_A/B/K`)

Головка не подменяется вторым знаком, а перетекает в белую булавку за 380 мс
(`1 − (1 − x)³`); выход — обратно. Кривая — линейная смесь двух наборов чисел
одинаковой формы `M x y c … a7 7 0 1 0-14 0 c … z` (холст 24):
`SIGHT_A = [12,17, 3.866,0, 7,-3.134, 7,-7, 0,3.866, 3.134,7, 7,7]` (круг),
`SIGHT_B = [12,21, 0,0, 7,-6.3, 7,-11, 0,4.7, 7,11, 7,11]` (булавка `pin`).
Зрачок `r = 2.6·t`; масштаб `k = 13/10.5 + (1 − 13/10.5)·t`; сдвиг вниз
`8.25·(1 − t)·k` px; обводка `2.154 → 1.6`. Знак 18 px, остриё — (9; 15,75)
от угла, заливка `--knob`, кант `--canvas` (светлая тема — `--knob-edge` и
тень `0 2px 5px --glass-cast`). Прицел обязан совпасть с поставленной
булавкой пиксель в пиксель. **У натива головка 20 pt (стекло ручки, 20г/20д)
и булавки 20 pt** — визир переносить в размерах натива, не веба.
Слово Алексея 24.09: «при нажатии на центр компаса, при построении маршрута,
тактильная отдача, значок трансформируется в булавку (это реализовано в pwa)».

## Набор точек (`lmap.on("click")`, `routeNewSpot`, `routeToggle`)

- Тап мимо булавки: открыта полоса имени — только закрыть её. Иначе в режиме
  — кольцо касания (`.map-tap`: 54, кант 1,4 латунь, `scale .3→1`, `opacity
  .6→0`, 0,44 с) и точка **в центре кадра**, не под пальцем: место под
  головкой уже сохранено — просто в черновик; нет — новое место (имя
  `uniqueSpotName(geoCity)` — «Лобня 2», иначе координаты; `named: !!geoCity`,
  `pinned: true`, 5 знаков) первым в списке и полоса имени с клавиатурой.
- Тап по булавке в режиме: в черновик / из черновика + тихая полоса имени.
  Карта не едет.
- Постановка — движение булавки `spot-land` 0,52 с `cubic-bezier(.2,.7,.3,1)`
  (`scale 2.2 rot −10° → 1.3 / 7° → 1.06 / −4° → .97 / 2° → 1`, ось — остриё),
  номер `no-land` 0,3 с с задержкой 0,16 (`scale .2→1.18→1`). Снятие — без
  движения. Отдача и щелчок — как у закладки (20г), слово Алексея 24.09.
- Номер на булавке `.sm-no`: кружок 15 латунью, цифра 9,5 / 700 цветом
  `--surface`, слева-сверху от знака (`left −18, top −20`).

## «✕» — снять черновик и «Вернуть» (`offerRouteUndo`, `showUndo(..., "route")`)

живые места обратно. Пока плашка висит, полоса держит прежнюю высоту

## Линия на холсте (`placeRoutePath`, `chainRuns`, `roadAsk`)

Слой под булавками, над вуалью. Куски — подряд идущие точки одного способа;
одно место дважды подряд — не переезд. Пока дороги нет — прямая штрихом:
2,2 латунь .45, `dash 6 6`. Дорога машиной: ореол 7,5 латунь .2 + линия
2,8 .95; пешком — точки `dash 0 5.6`, 2,8 .9. Дорогу спрашивают через 400 мс
тишины одним запросом на кусок: машина — `router.project-osrm.org/route/v1/
driving/…?overview=full&geometries=geojson`, пешком — Valhalla FOSSGIS
(`format=osrm`, `shape_format=geojson`, `directions_type=none`); ответ — линия,
км, минуты; сбой — в этом сеансе не спрашивать снова (кусок остаётся прямой).
**В паре у веба сети нет — там всегда прямые штрихом.**
**Натив — две реализации дороги, по переключателю источника карты в
настройках** (Алексей, 28.09, DECISIONS): у MapLibre — как у веба (OSRM /
Valhalla, те же запросы и кэш), у MapKit — карты Apple. Из документации, не
мерено: `MKDirections` строит путь A → B (`.automobile`, `.walking`) — запрос
на переход, а не на цепочку; у Apple есть предел частоты
(`MKError.loadingThrottled`) — ждать руку, как `roadAsk` (400 мс), кэш по паре
точек и способу. MapKit разрешён только в `LightPlanMapCanvas`
(`Tools/check_boundaries.sh`) — запрос дороги живёт там и говорит
координатами. У MapKit км и минуты разойдутся с вебом — по слову Алексея.
В паре линию сверять без ответа маршрутизатора (у веба там всегда штрих).
Демо-серверы OSRM / Valhalla по своим правилам не для приложений в магазине —
к выпуску (34) ветке MapLibre нужен свой или платный сервер (из правил, не
мерено нагрузкой).

## «Сделать съёмкой» (`makeRouteShoot`)

Жанр: выбранный, если у него есть маршрут (`hasRoute`), иначе первый
включённый с маршрутом; нет — ничего. Режим выключается, форма открывается
на выбранный день, начало — `SUN.goldB` (начало золотого часа) или минута
ползунка; точки дня — места черновика по порядку: без часов (`t`, `t2`
пусты), `p` = имя, `placeId` = id места, `walk` — из `mapWalk`. Первая точка —
место съёмки (`syncHeadPlace`). Черновик **остаётся** — его ставят и на
субботу, и на воскресенье. В нативе: `AppModel.openForm(day:start:)`,
точки — `AppModel+FormRoute.swift`.

## Ответы Алексея к 24а (28.09, DECISIONS)

1. Вход в режим — **круглая кнопка «Маршрут», как в PWA** («1 вопрос ответ -
   а»): в режиме тап в любом месте ставит точку в центр компаса, центр
   становится булавкой, отдача; кружок «Моё место» под кнопкой переносится.
2. Дорога — **две реализации по переключателю источника карты**: «приложение
   долго будет бесплатным, плюс будет бесплатная версия приложения, а значит
   нам нужны две реализации, потому в настройках есть переключатель источника
   карты».
