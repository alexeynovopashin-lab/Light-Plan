# Документы Light Plan

Порядок не случайный: от «зачем существуем» к «как выглядит конкретный экран».
Каждая новая идея проверяется этими документами. Если идея им противоречит —
меняется идея или меняется документ, но осознанно.

| 03 | [Principles](03_PRINCIPLES.md) | Продуктовые принципы |

Одиннадцатый документ появился позже остальных: продукт перерос замысел
солнечного калькулятора и встраивается в [Event OS](https://github.com/alexeynovopashin-lab/Event_OS) —
операционную среду мероприятия. Карточка события — точка стыковки, и её законы
приходят оттуда.

Отдельно — [Промпт для новой сессии](NEXT_SESSION.md): маршрут по документам и
текущая точка, чтобы не пересказывать переписку.

Отдельно — [Потребности](NEEDS.md): что просят на тестах и какой вопрос за
просьбой стоит. Не решение и не план, а материал для решения.

Рядом, в корне репозитория:

- [ROADMAP.md](../ROADMAP.md) — что сделано и что дальше
- [DECISIONS.md](../DECISIONS.md) — почему решено именно так и какие грабли уже пойдены

## С чего начинать новую сессию

Читать в этом порядке: этот файл → [11_EVENT_CARD](11_EVENT_CARD.md) (карточка)
→ [12_CARD_ARCHITECTURE](12_CARD_ARCHITECTURE.md) (группы жанров, матрица полей,
наложения, организации) → ROADMAP, раздел «Ближайшее» → DECISIONS, разделы
«Грабли» — чтобы не пойти по ним в третий раз.

Работа идёт в `beta/index.html`; релиз `index.html` получает тот же код, в нём
отличаются только две строки — имя приложения в заголовке. Хранилища разведены
по адресу (`/beta/`), поэтому данные каналов не пересекаются.
