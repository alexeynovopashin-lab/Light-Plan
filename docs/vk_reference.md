## 1. Что отдаёт публичная страница без входа (мерено)

Решает **заголовок User-Agent**, а не адрес:

| как представились | `vk.com/wall-19542789_200541` (реальный пост сообщества) | вывод |
|---|---|---|
| честно: `LightPlanLinkPreview/1.0 (+сайт)` | 302 → `m.vk.com`, 200, 103 КБ, `<title>ВКонтакте`, **без og-тегов**, без поста | оболочка входа: данных нет |
| `curl/…` | то же | то же |
| iPhone Safari | то же (103 КБ, 0,9–1,0 с) | то же |
| Mac Safari | 200, 995 КБ, 2,4–2,6 с: `og:image` (1920×1920), `og:description`, заголовок | данные есть |
| `TelegramBot (like TwitterBot)` | 200, 1,0 МБ, 2,3–2,8 с: `og:image` ×1, `og:description`, `og:title` | данные есть |
| `facebookexternalhit`, `Twitterbot` | 404 (в т.ч. на живой пост) | не пускают |

Итого: **без маскировки VK не отдаёт ничего**; данные получает только тот, кто выдаёт себя за браузер или бота Telegram.

По типам ссылок (Telegram-UA / Mac-UA, мерено):
- **пост** — `og:image` = **одна** картинка (первая; у поста с несколькими фото остальных в og нет), текст до ~150 знаков. Удалённый пост — **200** с заглушкой «Пост удалён» и общей картинкой VK (как `pin.it` и imgur: по коду не отличить, надо читать заголовок). Несуществующий — 404.
- **фото** `vk.com/photo-…` — og-тегов нет; в HTML внутренний JSON (`x_src`/`y_src`), структура не документирована. Несуществующее — 404.
- **альбом** `vk.com/album-…` — og нет, `<title>` с названием и числом фото, в HTML JSON со ссылками на фото.
- **сообщество** `vk.com/club…` / `vk.com/vk` — og нет, `<title>` общий, в JSON аватар `photo_200`; ни одного поста.
- Картинка `sunN-M.userapi.com/…` — открывается без входа: 200, `image/jpeg`, 380 КБ, 0,6–0,8 с (3/3). Адрес **подписан** (`sign=`), срок жизни не мерен.

`robots.txt` VK: `/wall-…` и `/photo-…` не закрыты (закрыто `?w=wall` и др.). Капчи и 403 не встретились; закрытое — это оболочка входа, а не отказ.

## 2. Достаёт ли Yandex Cloud (мерено из облака)

Нового кода в облако не клали, поэтому страницу целиком из облака прочитать не могли. Через `?pic=` (3/3): `userapi`-картинка из og — **200, 380 КБ, 0,8–1,8 с**;

Значит VK из облака **не отказывает на соединении**, но отдаёт ли он там настоящую страницу или оболочку/блок — **не мерено**.

## 3. Правила VK

- **Пользовательское соглашение VK, п. 6.3.9 (из текста):** без специального разрешения Администрации нельзя использовать автоматизированные скрипты (программы, боты, краулеры)
  для сбора информации на сайте. Чтение страниц нашим сервером **и** приложением с телефона под чужим User-Agent — как раз это, плюс подмена имени.
- **API (мерено):** `wall.getById`, `photos.getById`, `photos.get`, `groups.getById` без токена — `error_code 15, Access denied: token required` (3/3, 0,2–0,35 с).
  Нужен сервисный ключ **приложения VK**: приложение регистрируется под аккаунтом VK (у Алексея), ключ лежал бы в среде функции. Лимиты, обязательная проверка приложения и условия
  использования API — **не прочитаны** (`dev.vk.com` из инструмента чтения недоступен; цифры из памяти не приводим).
- **Сама по себе подмена бота** — тоже против «без имитации»: честное имя VK игнорирует.

## 4. Что можно положить в мудборд честно

Без входа и без токена **ничего честно взять нельзя**: единственный способ — выдавать себя за Telegram или браузер, что нарушает п. 6.3.9 и принцип «без имитации».
Если бы разрешили (API с ключом): пост — все фото поста + подпись; фото — оно само; альбом — до N первых; сообщество — только аватар/обложка (постов нет).
Через og, даже по запрещённому пути, достался бы только **один** кадр поста — не «все фото».

## 5. Варианты (решает Алексей)

1. **Ничего не делать с VK-страницами.** Ссылка VK остаётся обычной ссылкой («Открыть источник»), как сейчас. Прямые ссылки на `userapi`-картинки уже работают через 28н.1.
2. **«Поделиться → Light Plan»** (`docs/ideas.md`, Share Extension): человек сам делится фото из приложения VK; фото приходит файлом, никто ничего не собирает. Закрывает и VK, и Instagram, и Pinterest. Нужен App Group и расширение (бесплатная подпись — расширения проверить).
3. **API VK с сервисным ключом.** Единственный легальный автоматический путь; требует регистрации приложения VK, возможной проверки и чтения условий API; ключ в функции. Идёт вразрез с «нет своих сервисов/аккаунтов», пока Алексей сам не заведёт приложение.
