### Как не столкнуться с соседями

- Коммиты маленькие, по пункту. После каждого: `git fetch origin`, `git rebase
  origin/main`, прогон шлюза, `git push origin HEAD:main` (без force). Команды
  по одной — хук охраны режет склеенные строки.
- Конфликт при rebase в чужой функции — не решать за соседа: `git rebase
  --abort`, написать в чат, дождаться ответа.
- `beta/lang.js`: новые ключи — в конец своего блока, по всем языкам сразу;
  это самая частая точка конфликта.
- `ROADMAP.md` и `DECISIONS.md` — только вставка по свежему якорю / дописывание
  в конец, никогда не перезапись. DECISIONS склеивается `merge=union`.
- Вопрос к Алексею, который не даёт идти дальше — в чат с «Жду: Алексей», и
  переходи к следующему пункту своей ветки, а не простаивай.
